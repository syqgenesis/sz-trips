# sz-trips

Planning repo for founder trips from Silicon Valley to Shenzhen to visit robotics and hardware factories.

## Docs

- [Brand](brand/README.md): the Delta & Bay Founders Club logo (vector SVG and PNG), edge-glow backgrounds, colours and typeface.
- [Company structure & payments](docs/company-and-payments.md): which entity to use, how to collect money from US founders (ACH, cards, stablecoins), how to pay vendors in China in CNY, and the compliance checklist.
